Welcome to ColRadPy's documentation!
====================================

ColRadPy is a collisional-radiative solver for atomic data in the ADAS adf04
format. It computes level populations, photon emissivity coefficients (PECs),
generalized collisional-radiative coefficients and ionization balances.
