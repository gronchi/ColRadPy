=============================
ColRadPy Dictionary Structure
=============================

All data relavent to to a collisional radative is stored in the 'data' dictionary.
If data can be easily reproduced from data that is already stored in the dictionary
it is not store.


ColRadPy data
    atomic
    
    user
    
    input_file
    
    rates

        recomb
        
        ioniz
        
        burg_tully
        
    processed

    
**data**


+-------------------+-------------------------------------------------------+----------------+
|  key Name         | Description                                           | Data Type      |
+===================+=======================================================+================+
| atomic            |storage for data that is related to the atomic physics | dict           |
+-------------------+-------------------------------------------------------+----------------+
| user              | Data that was input by the user                       | dict           |
+-------------------+-------------------------------------------------------+----------------+
| input file        | Data from the input file (generally ADF04)            | dict           |
+-------------------+-------------------------------------------------------+----------------+
| rates             | Rates that go into the CR matrix ie excitation        | dict           |
+-------------------+-------------------------------------------------------+----------------+
| cr_matrix         | CR matrix and other matrix relate quanities           | dict           |
+-------------------+-------------------------------------------------------+----------------+
| processed         | processed quantities from the calculation             | dict           |
+-------------------+-------------------------------------------------------+----------------+

**projection**

Only with the projection option, see the theory manual. The first index of couplings and parent_coupling is the level or parent populated; with temp_dens_pair the temperature and density axes are one pair axis.

+---------------------------------+-------------------------------------------------------------------+----------------+-------------------------------------------+
| key Name                        | Description                                                       | Data Type      | Size                                      |
+=================================+===================================================================+================+===========================================+
| couplings                       | transfers between levels through the high n-shells (s-1)          | array          | (len(energy), len(energy), temp, dens)    |
+---------------------------------+-------------------------------------------------------------------+----------------+-------------------------------------------+
| ionization                      | ionization of the levels through the high n-shells (cm3 s-1)      | array          | (len(energy), len(ion_pot), temp, dens)   |
+---------------------------------+-------------------------------------------------------------------+----------------+-------------------------------------------+
| recombination                   | recombination into high n-shells reaching the levels (cm3 s-1)    | array          | (len(energy), len(ion_pot), temp, dens)   |
+---------------------------------+-------------------------------------------------------------------+----------------+-------------------------------------------+
| parent_coupling                 | parent to parent through the high n-shells, added to XCD (cm3 s-1)| array          | (len(ion_pot), len(ion_pot), temp, dens)  |
+---------------------------------+-------------------------------------------------------------------+----------------+-------------------------------------------+
| groups                          | indirect couplings of each parent and spin system, adf17 grid     | list           | -                                         |
